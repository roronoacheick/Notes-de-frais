Analyse cette image de justificatif de dépense professionnelle et extrais toutes les informations disponibles.

{

## Détail des champs
 
| Champ               | Type    | Format / Valeurs possibles                                              |
|---------------------|---------|-------------------------------------------------------------------------|
| date                | string  | Format ISO 8601 : "YYYY-MM-DD". Ex : "2025-06-03"                      |
| montant_ttc         | number  | Montant total toutes taxes comprises, en nombre décimal. Ex : 24.50    |
| montant_ht          | number  | Montant hors taxes, en nombre décimal. null si non indiqué             |
| tva                 | number  | Montant de la TVA, en nombre décimal. null si non indiqué              |
| devise              | string  | Code ISO 4217 à 3 lettres. Ex : "EUR", "USD", "GBP". Défaut : "EUR"   |
| categorie           | string  | Une des valeurs : "restaurant", "transport", "hebergement",             |
|                     |         | "carburant", "fournitures", "autre"                                     |
| fournisseur         | string  | Nom de l'enseigne ou de l'entreprise émettrice du justificatif         |
| adresse_fournisseur | string  | Adresse postale du fournisseur si visible. null sinon                  |
| numero_document     | string  | Numéro de ticket, de facture ou de réservation. null si absent         |
| mode_paiement       | string  | Une des valeurs : "carte", "especes", "virement", "autre", null        |
| description         | string  | Courte description du contenu de la dépense (ex : "Déjeuner client")  |
| note                | string  | Toute information utile non couverte par les autres champs. null sinon |
 
## Règles strictes
 
- Retourne UNIQUEMENT le JSON, sans texte avant ni après.
- N'utilise pas de balises Markdown (pas de ```json).
- Si un champ est illisible ou absent du document, sa valeur doit être `null`.
- Ne devine jamais une valeur : si tu n'es pas certain, mets `null`.
- Les montants sont des nombres (pas des chaînes) : 24.50 et non "24.50".
- La date doit toujours être au format "YYYY-MM-DD".
